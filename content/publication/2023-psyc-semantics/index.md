abstract: >-
  This paper develops semantic foundations for PsyC, an industrial real-time
  language combining concepts from Synchronous-Reactive programming and Logical
  Execution Time. It uses the Synchronous Logical Execution Time framework to
  relate the native temporal behavior of PsyC programs to synchronous models,
  providing a basis for subsequent formal verification.
