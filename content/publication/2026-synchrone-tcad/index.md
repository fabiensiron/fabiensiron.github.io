abstract: >-
  This work presents Frama-C/Synchrone, a methodology and plug-in for extracting
  synchronous-reactive models from cyclic C programs. The approach constructs a
  symbolic transition system using program-analysis techniques and simplifies
  memory interactions in order to generate Lustre models that can subsequently
  be analyzed by synchronous verification tools.
